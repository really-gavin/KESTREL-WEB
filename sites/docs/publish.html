Publishing a site on the Kestrel web

A site is a folder in the sites directory of the Kestrel web repository. It needs an index.html page and a site.txt file with a name, an owner, a description and some tags.

Use headings, paragraphs, lists and links. Scripts, styles and images are ignored. Link to other sites with relative links such as ../home/. After you add your folder, run the indexer so the search engine finds your pages.
